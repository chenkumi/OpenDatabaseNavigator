## 修復內容
- `src/main/database/adapters/sybase/sybase-adapter.ts`：以 Node `createRequire` 延遲載入選用 CommonJS 原生驅動，避免 `msnodesqlv8` 不存在時 TypeScript 編譯失敗。保留 ASE ODBC 驅動／SAP 驅動缺失時的明確錯誤；沒有繞過 Command Bus 或權限。
- `tests/sybase-optional-driver.test.ts`：新增缺失原生依賴的回歸測試，驗證建立 adapter 不載入驅動、連線時才載入並回報既定錯誤。
- `tests/mcp.test.ts`：將 130 個同時建立的 TCP 連線改為 13 批、每批 10 個並行 HTTP 要求；保留完整額度測試並加強至精確斷言 120 個 401、10 個 429，以及有效 token 為 400（尚未初始化 MCP），而不是只排除 401／429。
- MCP 失敗可在最小 Node HTTP server 重現：130 個同時 fetch 得到 129 個成功、1 個 ECONNRESET；本機 `kern.ipc.somaxconn=128`。這是测试對系統接入佇列的依賴，不是需要修改產品限流政策。
- `tests/sybase-io.test.ts`：測試伺服器固定綁定可攜的 127.0.0.1，由測試 connector 導向 fixture；保留 production relay 對原始目標 127.0.0.2 的 TLS 身分檢查、真實憑證驗證與「未送出登入」斷言。不需要 macOS loopback alias。
- `scripts/smoke-electron.mjs`：等待設定對話框開場動畫完成才量測捲動前後位置；依平台使用 macOS Cmd／Option 快捷鍵及 Windows／Linux Ctrl 快捷鍵，保留查詢選取範圍與 SQL 歷史斷言。
- `scripts/capture-desktop.mjs`：寫入截图前建立父目錄，讓新工作目錄不需事先建立 `.local`。
- `scripts/ui-controls.mjs`：以鍵盤開啟 Base UI select，避免對齊的選項接到開啟 click 的釋放事件；以 trigger 的 aria-controls 定位正確 listbox，避免前一 popup 的退出動畫造成雙重匹配。檢查開啟與關閉狀態，沒有 force click 或跳過斷言。
- `README.md`：補齊 Windows／macOS／Linux 建置需求、選用 ODBC 原生工具鏈、Electron 下載、Docker／pg_dump／PowerShell／SAP 工具選裝需求，區分展開應用與安裝檔、列出不會上傳的安裝檔產製指令及簽章／公證限制。

## 選用 ODBC 的環境發現
此次系統沒有 unixODBC。檢查 msnodesqlv8 5.5.0 官方套件內的 macOS arm64 預編譯檔，`otool -L` 顯示其依賴 `/opt/homebrew/opt/unixodbc/lib/libodbc.2.dylib`；直接載入該二進位回報該 dylib 不存在。README 已指示需要 ASE ODBC 時先 `brew install unixodbc` 再安裝套件／驗證載入。一般資料庫功能不需要此驅動，因此本次沒有全機安裝它。SAP ASE 仍未做真機驗證。

### DMG 工具下載處理
預設 electron-builder 在下載 dmgbuild-bundle 時等待逾時；直接下載也證實網路速度約 80 KB/s，不是缺少 Python 的錯誤。最終以續傳完成官方 `dmg-builder@1.2.5` 的 arm64 工具封包，核對 electron-builder 內建 SHA-256 `793404d0c96687e27d5ee40a668d498c92e36a64d6c2906df511031adb33cbeb` 成功後，使用 `CUSTOM_DMGBUILD_PATH` 指向暫存目錄的官方 dmgbuild 執行。這是本機下載的環境處理，不改寫依賴或套件碼。

實際成功命令：
```sh
CUSTOM_DMGBUILD_PATH=<已核對官方封包的 dmgbuild 絕對路徑> CSC_IDENTITY_AUTO_DISCOVERY=false npm exec -- electron-builder --mac dmg --arm64 --publish never
hdiutil verify 'release/Database Workspace-0.1.0-arm64.dmg'
```
`CSC_IDENTITY_AUTO_DISCOVERY=false` 僅為此次未簽章本機驗證，不能當成正式發布設定。
