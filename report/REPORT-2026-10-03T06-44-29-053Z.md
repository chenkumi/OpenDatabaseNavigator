# WSL 已知問題修復與驗證

日期：2026-10-03。基準提交：`d42ed8e`。環境：Ubuntu 24.04.4 / WSL2 x86_64、Node.js 24.18.0、npm 12.0.2、Electron 44.4.5。

## 修復內容

### SQLite 原生呼叫無法硬取消

`src/main/database/adapters/sqlite/sqlite-adapter.ts` 原先使用 JS Worker；當 SQLite 在同步原生呼叫中執行時，terminate() 不能及時中斷，下一個寫入等待 10 秒後會失败。

改用獨立 Node/Electron-as-Node 子程序，沿用既有 SQL 執行與結果上限、PRAGMA、DDL 交易、唯讀政策及回傳型別。取消／逾時使用 SIGKILL，替代 session 必須等待原程序真正退出，避免競爭 SQLite 檔案鎖。使用 advanced IPC serialization 保留二進位參數；新增 startup deadline、並行 connect 合併、startup/disconnect 競爭處理及 IPC error 清理。沒有繞過 Application Command Bus、權限或 renderer IPC 邊界。

新增 `tests/sqlite-process.test.ts` 六項回歸案例：原生寫入逾時後釋放鎖與回滾、AbortSignal 取消、disconnect 中斷、並行連線與記憶體/BLOB 參數、startup/disconnect 競爭、startup 失敗清理。

取消不會撤銷先前已提交的操作；終止記憶體 session 會遺失該 session 的資料，與先前重建 Worker 的限制一致。

### WSLg 隱藏桌面 smoke 卡住

`scripts/ui-controls.mjs` 改以真實鍵盤 Enter 選取 Base UI option，保留 option 可見與 popup 關閉斷言，不使用 force click。

`scripts/smoke-electron.mjs` 在 WSL 顯示隔離測試視窗，以保證真實拖曳可取得 compositor frame；其他平台仍沿用隱藏視窗模式。禁用 JS background throttling 本身不足以解決這次隱藏視窗的幀等待。修正後原本卡住的下拉選取、tab drag reorder 及完整流程全部完成。

### Linux 安全儲存診斷與使用者指引

新增 `scripts/check-secure-storage.mjs` 與 `npm run check:secure-storage`。以真正 Electron、隔離 profile、固定非機密測試字串檢查 backend、可用性及加解密往返；有 30 秒期限與清理，不讀取既有密碼。不接受 basic_text，不傳回測試密文或任何憑證。

`src/main/credentials/credential-service.ts` 的 Linux 錯誤加入安裝／解鎖 Secret Service 與診斷命令提示，仍拒絕不安全的密碼儲存。新增 `tests/credentials.test.ts` 三項測試，確認不可用時不加密、不解密、不保存明文，也不在錯誤中暴露輸入秘密。

`docs/USER_GUIDE.md` 補充 Ubuntu/WSL keyring 安裝、非空主密碼與手動解鎖、backend 選擇、診斷與啟動方式、WSL smoke 與 SQLite 取消語義。官方 safeStorage 文件已查閱： https://www.electronjs.org/docs/latest/api/safe-storage 。
