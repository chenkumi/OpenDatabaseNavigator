# Plan：Linux／WSL 啟動設定、安全儲存引導與發行包驗收

將 backend 選擇整合進應用程式本身，讓已配置安全 keyring 的使用者直接啟動 Linux 發行包即可保存密碼，不再依賴額外的 npm 指令、桌面環境變數或啟動參數。當安全儲存不可用時提供清楚、可操作的引導，並以真正發行包驗證直接啟動、憑證持久化與重啟後解密。

> 本計畫使用 execute-plan 技能執行。Checkbox（`- [ ]`）語法為追蹤格式。建立時僅規劃；目前五個 checkpoint 均已完成獨立驗證，不自動 commit／push／發布。

## Scope

- In：Linux／WSL 啟動 backend 策略、共用安全儲存狀態／診斷、繁中／英文引導、Linux x64 展開包與 AppImage 產製、隔離的發行包憑證往返及負向測試、README／使用指南與驗收紀錄。
- In：保留 Windows／macOS 的現行行為；透過單元測試驗證不套用 Linux 策略，不宣稱在目前 WSL 已完成這兩個平台的實機驗收。
- Out：自動 sudo／安裝或解鎖系統 keyring、空密碼 keyring、basic_text／明文備援、強制所有 Linux 使用 GNOME、切換或遷移既有憑證 backend、OAuth、真實外部資料庫整合、deb/rpm/Flatpak、其他架構、正式簽章／發布上傳、自動 commit/push。
- 交付假設：沿用目前 AppImage 目標；keyring 安裝／解鎖是明示的系統前置條件，不把這部分偽裝成應用可以免設定完成。

## 已確認的事實與環境限制

- 基準提交為 `5834fa3`；建立計畫時 main 與 origin/main 同步，工作目錄乾淨。
- `src/main/index.ts` 尚無安全儲存啟動選擇策略，已拒絕 Linux basic_text；初始化入口為 app.whenReady().then(boot)。
- 当前 WSL 的明確 libsecret 檢查及正式程式保存／重啟解密已通過；無參數預設啟動仍選 basic_text。org.freedesktop.secrets 已存在。
- `npm run package` 是 electron-builder --dir，產生展開包；`build.linux.target` 是 AppImage。尚無 release 產物。
- `scripts/smoke-packaged.mjs` 委派給 Playwright Electron launcher；其 loader 強制 password-store=basic，不適合作為真實 keyring 驗收工具。
- `scripts/check-secure-storage.mjs` 目前是獨立的 Electron probe，尚未與正式 app 共用啟動策略。
- 主程序已有固定 IPC sender 驗證，renderer 透過 Command Bus；SettingsPanel 與現有 i18n 可承載狀態及引導，不需增加任意檔案或 shell 存取。
- 本機僅確認有 libfuse3，未確認所產製 AppImage 可無參數啟動。執行時須先核對實際 builder runtime 與 FUSE／sandbox 需求；缺少系統前置條件需記錄阻塞並由使用者處理，不以 --no-sandbox 或 extract-and-run 冒充正常發布驗收。
- 外部依據：已查閱 Electron safeStorage／CommandLine 官方文件；本機 electron-builder linuxOptions.d.ts 可確認 desktop／executableArgs 與 AppImage runtime 工具選项。網站 AppImage 文件讀取逾時，封裝細節以已安裝版本的型別／實作及實際產物驗證為準。

## Files

以下新增路徑為預定責任邊界；實作前需與現有命名及測試結構核對。

- `src/main/credentials/storage-bootstrap.ts`（新增）：可測試的启动策略與前置設定；在 app ready／安全儲存初始化之前執行。
- `src/main/credentials/secure-storage-service.ts`（新增）、`src/main/credentials/credential-service.ts`：統一安全狀態、健康檢查、錯誤分類與原有加解密防護。
- `src/main/index.ts`：接入 bootstrap、注入共用服務，註冊 humanOnly 的狀態查詢 Command Bus 命令。
- `src/shared/types.ts`：定義 `SecureStorageStatus`，只含 platform、backend、available、selectionSource、reason、restartRequired 等非機密欄位，不混入密碼或密文。
- `src/renderer/src/components/SettingsPanel.tsx`、`ConnectionForm.tsx`、`src/renderer/src/i18n.tsx`：安全儲存狀態、設定指引、重新檢查及保存失敗提示；沿用固定 IPC 與既有 UI 元件。
- `scripts/check-secure-storage.mjs`：接入與正式 app 一致的選擇策略，保留明確 backend 參數覆寫與退出碼規則。
- `scripts/smoke-packaged-credentials.mjs`（新增）：正常程序啟動加標準自動化附加，驗證真正 backend、保存、重啟與解密；不使用強制 basic 的 Electron loader。
- `tests/secure-storage.test.ts`（新增）、`tests/credentials.test.ts`：啟動策略、狀態命令權限、安全失敗與憑證不洩漏測試。
- `package.json`：新增 `test:packaged:credentials` 指令，確認 Linux 發行 metadata、產物命名及 AppImage 設定；不全域固定 GNOME 參數。
- `README.md`、`README.en.md`、`docs/USER_GUIDE.md`：同步無參數啟動、系統前置條件、疑難排解及發行包驗收方式。完成結果另以 note 工具建立 report。
